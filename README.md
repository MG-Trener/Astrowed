# Astrowed · Digital Destiny Lab

Русскоязычная платформа Ба Цзы, Фэн Шуй и Ци Мэнь на Next.js 16, React и Neon PostgreSQL. Эксперт проекта — Юлия Гаврилычева. Реализованы девять дворцов Ци Мэнь, Гуа, расширенные слои Ба Цзы и три формата отчётов. Границы автоматической интерпретации и следующие шаги описаны в [плане расширения](docs/EXPANSION_ROADMAP.md).

Выбор места: страна и поиск по справочнику GeoNames (235 878 населённых пунктов). Выбранный результат одновременно задаёт координаты и IANA-пояс; смещение UTC рассчитывается на дату рождения. Несогласованный ввод блокирует расчёт. Для отсутствующих мест доступен ручной ввод с обязательными координатами и часовым поясом. Справочник загружается с сайта частями по странам, без внешнего геокодинга. Источник, лицензия, покрытие и обновление: [public/locations/README.md](public/locations/README.md). Supabase не используется; серверная БД — Neon PostgreSQL.

## Запуск

Требуется Node.js 22+.

```sh
npm ci
# Скопируйте .env.example в .env и заполните DATABASE_URL / DATABASE_URL_UNPOOLED
npm run setup:workspace
npm run dev
```

Откройте http://127.0.0.1:3000. Пароль кабинета — значение `WORKSPACE_PASSWORD` в локальном `.env`. Скрипт создаёт случайный пароль и подпись сессии, не выводит их и не меняет уже настроенные значения.

## База данных

Drizzle, схема `astrowed`. Используйте dev-ветку Neon и непулированное соединение для миграций. Миграции не запускаются на старте приложения. После проверки целевой БД установите `ALLOW_DB_MIGRATION=true` только на время команд:

```sh
npm run db:migrate
npm run db:seed
```

Seed идемпотентный, существующие статьи не перезаписывает. Секреты запрещено коммитить. `.env` исключён из Git.

## Проверки

```sh
npm test
npm run typecheck
npm run build
npm audit
```

`npx tsx scripts/verify-integration.ts` требует работающий dev server, Neon и настроенный кабинет; сохраняет одну явно демонстрационную карту, проверяет API и PDF. Тест консультации выполняется внутри транзакции с ROLLBACK.

## PDF и размещение

PDF формируется на сервере через Chromium. Windows автоматически использует установленный Edge. Linux: `npx playwright install --with-deps chromium`, установите CJK fonts. Для собственного Chromium задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

`npm run build` создаёт standalone-сборку. Dockerfile предназначен для Railway/Debian. Vercel поддерживает web-приложение; для PDF нужен отдельный Chromium runtime/сервис, совместимый с лимитами функций. Полная серверная версия пока не опубликована.

### GitHub Pages

Публичная версия: https://astrowed.amratlas.kz/. Отдельное приложение `apps/pages` использует общие компоненты, стили и расчётное ядро. `npm run build:pages` создаёт статические файлы в `apps/pages/out` для корня домена; `npm run verify:pages` проверяет маршруты и пути ресурсов. Локальный `next dev apps/pages` сохраняет префикс `/Astrowed`. Для публикации в подпапке задайте одинаковый `NEXT_PUBLIC_BASE_PATH` при сборке и проверке. Пользовательский домен и HTTPS настроены в GitHub Settings → Pages; при публикации через Actions файл CNAME не требуется.

На Pages работают калькуляторы Ба Цзы, Гуа и Ци Мэнь, временные слои, символические звёзды, Багуа, материалы Фэн Шуй и библиотека с графом. Данные рождения не отправляются на сервер. Предпросмотр поддерживает краткий, полный и профессиональный отчёт с сохранением в PDF средствами браузера. База клиентов, авторизация, редактор статей и серверный PDF доступны в полной версии, требующей Node.js-хостинга. Сборка Pages не подключается к Neon и не требует секретов. Материалы библиотеки на Pages — справочник из кода, изменения CMS туда автоматически не попадают.

Workflow `.github/workflows/pages.yml` собирает и публикует Pages при push в `main` или `codex/destiny-lab-foundation`. В Settings → Pages источником должен быть GitHub Actions; окружение `github-pages` должно разрешать выбранную ветку. После слияния foundation-ветки можно оставить автоматическую публикацию только из `main`.

## Границы версии

- Кабинет одного консультанта; полноценные OAuth/роли/tenant isolation — следующий этап. Neon Auth пользователя не изменён и пока не интегрирован.
- Расчётный адаптер lunar-typescript 1.8.6: солнечные термины, локальные день/час, два правила смены дня, среднее солнечное время, Да Юнь, десять богов, скрытые стволы, На Инь.
- Доли элементов не равны оценке силы карты. Истинное солнечное время, сезонные веса, трансформации, полный набор взаимодействий требуют верифицированных методик.
- PDF: три формата, generated-обложка, Ба Цзы, Гуа, Ци Мэнь, комментарий и контакты; QR и визуальный редактор структуры ещё не реализованы.
- CMS: текст, публикация, черновики, категории из начального набора, источники. Управление медиа и расширенная редакционная модель впереди.

Источники календарного адаптера: [lunar-typescript](https://github.com/6tail/lunar-typescript), [официальная документация lunar](https://6tail.cn/calendar/api.html). Подробности: `docs/` и `TODO.md`.
