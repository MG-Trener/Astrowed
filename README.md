# Astrowed · Digital Destiny Lab

Русскоязычная лаборатория Ба Цзы на Next.js 16, React и Neon PostgreSQL. Репозиторий содержит первое рабочее приложение, а не завершённую профессионально сертифицированную платформу.

## Запуск

Требуется Node.js 22+.

```sh
npm ci
# Скопируйте .env.example в .env и заполните DATABASE_URL / DATABASE_URL_UNPOOLED
npm run setup:workspace
npm run dev
```

Откройте http://127.0.0.1:3000. Пароль кабинета — значение `WORKSPACE_PASSWORD` в локальном `.env`. Скрипт создаёт случайный пароль и подпись сессии, не выводит их и не меняет уже настроенные значения.

## База данных

Drizzle, схема `astrowed`. Используйте dev-ветку Neon и непулированное соединение для миграций. Миграции не запускаются на старте приложения. После проверки целевой БД установите `ALLOW_DB_MIGRATION=true` только на время команд:

```sh
npm run db:migrate
npm run db:seed
```

Seed идемпотентный, существующие статьи не перезаписывает. Секреты запрещено коммитить. `.env` исключён из Git.

## Проверки

```sh
npm test
npm run typecheck
npm run build
npm audit
```

`npx tsx scripts/verify-integration.ts` требует работающий dev server, Neon и настроенный кабинет; сохраняет одну явно демонстрационную карту, проверяет API и PDF. Тест консультации выполняется внутри транзакции с ROLLBACK.

## PDF и размещение

PDF формируется на сервере через Chromium. Windows автоматически использует установленный Edge. Linux: `npx playwright install --with-deps chromium`, установите CJK fonts. Для собственного Chromium задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

`npm run build` создаёт standalone-сборку. Dockerfile предназначен для Railway/Debian. Vercel поддерживает web-приложение; для PDF нужен отдельный Chromium runtime/сервис, совместимый с лимитами функций. Публичное размещение ещё не выполнено.

## Границы версии

- Кабинет одного консультанта; полноценные OAuth/роли/tenant isolation — следующий этап. Neon Auth пользователя не изменён и пока не интегрирован.
- Расчётный адаптер lunar-typescript 1.8.6: солнечные термины, локальные день/час, два правила смены дня, среднее солнечное время, Да Юнь, десять богов, скрытые стволы, На Инь.
- Доли элементов не равны оценке силы карты. Истинное солнечное время, сезонные веса, трансформации, полный набор взаимодействий требуют верифицированных методик.
- PDF — краткий отчёт; QR, полный консультационный отчёт и визуальный редактор отчётов ещё не реализованы.
- CMS: текст, публикация, черновики, категории из начального набора, источники. Управление медиа и расширенная редакционная модель впереди.

Источники календарного адаптера: [lunar-typescript](https://github.com/6tail/lunar-typescript), [официальная документация lunar](https://6tail.cn/calendar/api.html). Подробности: `docs/` и `TODO.md`.
