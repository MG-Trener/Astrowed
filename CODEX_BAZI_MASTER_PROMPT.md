# Master Prompt для Codex — BA ZI / Four Pillars

Ты — Lead Product Designer, Creative Director, Senior Full-Stack Engineer и архитектор интерактивных premium web-продуктов.

Твоя задача — спроектировать и реализовать современную цифровую платформу для профессиональной работы астролога/консультанта Ба Цзы.

Это НЕ должен быть типовой сайт астролога, лендинг на готовом шаблоне, стандартный dashboard или набор обычных карточек Bootstrap/Tailwind.

Нужен продукт уровня premium digital experience с выраженным WOW-эффектом, который будет выглядеть как сочетание:

- футуристической обсерватории;
- древней китайской метафизики;
- интерактивного атласа судьбы;
- современного аналитического SaaS;
- sci-fi интерфейса;
- digital art;
- premium luxury visual experience.

Главное требование:

> ПРИ ПЕРВОМ ОТКРЫТИИ САЙТА ПОЛЬЗОВАТЕЛЬ ДОЛЖЕН ПОДУМАТЬ:  
> «Я такого сайта по Ба Цзы раньше не видел».

При этом эффектность не должна вредить удобству, скорости, читаемости и профессиональной работе консультанта.

## 2. Технологическая архитектура

Используй современный production-ready стек.

### Frontend

- Next.js latest stable;
- React;
- TypeScript;
- Tailwind CSS только как foundation, но НЕ использовать стандартный Tailwind-look;
- Framer Motion;
- GSAP там, где нужны сложные timeline-анимации;
- Three.js / React Three Fiber для ключевых WOW-сцен;
- SVG;
- Canvas/WebGL там, где это действительно улучшает интерфейс.

### Backend

- Next.js Server Actions/API либо отдельный Node.js backend, если архитектурно оправдано;
- TypeScript;
- строгая валидация входных данных;
- модульная архитектура.

### Database

- Neon PostgreSQL.

### ORM

- Prisma либо Drizzle.

### PDF

- серверная генерация PDF;
- предпочтительно HTML/CSS → PDF через Playwright/Puppeteer;
- отчёт должен визуально соответствовать бренду сайта.

### Authentication

- заложить архитектуру авторизации;
- роли;
- возможность дальнейшего подключения OAuth.

### Deployment

Проект должен быть готов к:

- Vercel;
- Railway;
- собственному Debian-серверу.

Neon используется как внешняя PostgreSQL БД.

### Environment

- все секреты только через ENV;
- `.env.example`;
- никаких credentials в репозитории.
