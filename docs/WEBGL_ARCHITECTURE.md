# Rendering strategy

Фон сайта: WebGL 1 без сторонних 3D-библиотек, загружается через dynamic import из `celestial-sky.tsx`. Галактики используют текстуру с анимированными координатами, взрыв звезды — процедурную объёмную оболочку. Созвездия и кометы сохраняют SVG/CSS. Основная интерактивная сцена элементов не меняется.

Предусмотрены восстановление после context loss, статический fallback, reduced motion, остановка скрытой вкладки и ручная пауза. Профессиональный режим также останавливает фон. Ограничены частота отрисовки и размер drawing buffer; GPU/FPS на разных устройствах не гарантируются. Жизненный цикл, тайминг и проверки описаны в `SKY_EVENTS.md`.
