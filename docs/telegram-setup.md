# Заявки эксперту в Telegram

1. Откройте официальный [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя и username, заканчивающийся на `bot`.
2. Создайте **закрытый канал** «Astrowed · заявки». Добавьте эксперта. В заявках будут персональные анкеты: не используйте публичный канал.
3. Добавьте бота администратором с правом публикации сообщений. Остальные права ему не нужны.
4. В корне проекта создайте `.env.telegram.local`:

```dotenv
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
```

Вставьте токен после `TELEGRAM_BOT_TOKEN=`. Не отправляйте токен в чат, репозиторий или скриншоты. Файл исключён из Git.

5. Напишите в канале «Проверка Astrowed». Запустите из корня проекта `node scripts/check-telegram.ts`. Скрипт покажет ID найденных каналов без содержимого сообщений. Вставьте нужный ID в `TELEGRAM_CHAT_ID` и повторите проверку. Скрипт проверяет бота и права, но ничего не отправляет.
6. Передайте обе переменные в серверное окружение Neon Function `accountapi` выбранной ветки. Не используйте префикс `NEXT_PUBLIC_`. Локальный файл сам по себе не настраивает облачную функцию.
7. После серверного подключения отправьте тестовую заявку из кабинета с тестовой анкетой и согласием на передачу. Проверьте поступление в канал и статус в кабинете администратора. Доставку считать проверенной только после этого шага.

## Поведение приложения

Заявка доступна после входа и сохранения анкеты рождения. Сервер берёт контакты и анкету текущего пользователя из базы, проверяет отдельное согласие на Telegram и ограничивает частоту заявок. Сообщение включает имя, телефон, почту, данные рождения, город проживания и вопрос.

Заявка сохраняется до обращения к Telegram. При неподтверждённой доставке она остаётся доступна эксперту в кабинете; автоматического повторения нет, чтобы избежать дублей. Пока настройки отсутствуют, интерфейс сообщает о недоступности отправки.

Инструкция основана на [документации BotFather](https://core.telegram.org/bots/features#botfather) и [Telegram Bot API](https://core.telegram.org/bots/api).
