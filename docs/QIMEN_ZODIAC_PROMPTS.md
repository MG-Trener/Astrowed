# Generated zodiac animals

Built-in image_gen, 12 separate generations, transparent backgrounds. Final site assets are 384px WebP with preserved alpha in `src/assets/generated/zodiac/`. Full size originals remain in the image generation output directory. Images decorate existing fixed branch-to-palace mappings; they do not carry calculation text. The original SVG linework is retained for printing and image-load fallback.
