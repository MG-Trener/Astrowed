# PDF-отчёты

Единый экранирующий HTML-шаблон reportHtml(chart, options) используется серверным Playwright PDF и клиентским iframe preview/печатью. Три уровня: brief, full, professional. Клиент может добавить собственный комментарий; он не приписывается автоматически эксперту.

- Краткий: обложка, столпы, распределение, основные пояснения, такты, методика и контакты.
- Полный: подробные пояснения, текущие энергии, Шэнь Ша, Гуа, Ци Мэнь, десять годовых слоёв.
- Профессиональный: дополнительно 100 лет и таблица скрытых стволов/десяти богов/На Инь/фаз.

Неизвестное время: час, Да Юнь и Ци Мэнь не выдумываются. Интерпретация силы карты остаётся экспертной.

API POST /api/reports/[id] сохраняет авторизацию, Origin guard, private/no-store; принимает level и comment до 5000 знаков. Сервер встраивает обложку data URI, запрещает внешние сетевые загрузки и добавляет нумерацию страниц. Docker и output tracing включают WebP обложки.

На GitHub Pages доступен предпросмотр и системная печать в PDF. Для прямой серверной загрузки нужен развёрнутый сервер и кабинет. Комментарий браузерного предпросмотра не сохраняется в БД.

QA-скрипт scripts/render-report-samples.ts создаёт три локальных тестовых PDF из самодостаточного HTML без открытия сайта. Результаты находятся в игнорируемой artifacts/expansion-pdf; их не коммитим. Рендерим страницы Poppler и осматриваем таблицы, символы и переносы.
