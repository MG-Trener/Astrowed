# The quiet observatory

Визуальная идея — точный оптический прибор в тёмном пространстве. Нефрит, дымчатое серебро, тёплая Земля, приглушённый Огонь. Типографика нейтральная: Segoe UI / системный sans; CJK отдельно serif. Главный акцент — форма и масштаб, не neon saturation.

Hero: четыре слоя орбит, центральное ядро, пять точек элементов. Матрица: вертикальные столпы, стволы и ветви как самостоятельные объекты. Timeline: непрерывная шкала. Explore: управляемый граф порождения/контроля. Кнопки и формы сохраняют знакомую эргономику.

Первый визуальный цикл выполнен в SVG/CSS. Материальные WebGL-сигнатуры каждого элемента и spatial morph — следующий художественный этап, не заявлены как реализованные.
