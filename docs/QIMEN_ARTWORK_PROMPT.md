# Generated palace surface

Created with the built-in image_gen tool. Project asset:
`src/assets/generated/qimen-palace-jade.webp` (WebP encoding of the generated PNG).
The nine interactive cells share this decorative surface. All calculated text,
zodiac controls, selection, layer filters and print content remain live UI.
