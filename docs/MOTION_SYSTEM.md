# Motion system

Токены в `src/styles/motion-tokens.ts`. Hover 180–250 ms; спокойные переходы 400 ms; вводная сборка 2.1 s; орбиты 160 s на оборот. Вводная сцена пропускается и запоминается в sessionStorage.

`prefers-reduced-motion` выключает переходы/циклы/intro. Профессиональный режим останавливает орбиты и сокращает hero. Сцены остаются доступны без анимации. Аудио не используется.
