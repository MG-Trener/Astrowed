# Анимация расширения

Сохранена существующая космическая сцена главной с паузой и reduced-motion. Новые эффекты: спокойное увеличение изображения карточки, смена рамки выбранного дворца, смена слоёв, лёгкое поднятие кнопки и проходящий блик по минералу.

Длительность интерфейса 200–300 мс, блик 800 мс; трансформации не сдвигают layout. prefers-reduced-motion отключает новые transitions/transforms. Работа форм, выбор дворцов и печать не зависят от анимации. Высокочастотного фонового движения в новых модулях нет.

Кнопки: скошенный силуэт, металлическая кромка, generated jade texture у primary. Контраст проверяется в normal/hover, клавиатурный фокус виден внутренней светлой рамкой, disabled не анимируется.
