# Initial audit

На входе — только два текстовых технических задания, существующего UI нет. Переработки старых компонентов не требуется.

Риски: обычные dashboard-карточки, чрезмерный неоновый glow, мелкий технический текст, декор вместо работающих данных. Решение: крупная спокойная типографика, единая орбитальная геометрия, разреженные разделители, цвет по элементу, визуальные сцены в роли инструментов.
