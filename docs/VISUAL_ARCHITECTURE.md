# Visual architecture

Обсерватория времени: глубокий чернильный фон, дымчато-белая типографика, нефритовые и янтарные акценты. Главное визуальное тело — система орбит с пятью материальными сигнатурами, центр — Господин дня. Четыре столпа — вертикальные каналы, а не одинаковые SaaS-карточки.

SVG/CSS — основной portable renderer; не требуют GPU/WebGL. Сцены получают нормализованные данные и могут быть заменены на Three.js без изменения движка. Только transform/opacity для фоновой анимации. Reduced motion отключает циклы, компактный режим сокращает декоративное пространство.

Модули: HeroScene, ElementsReactor, DestinyMatrix, Timeline. Hover дублируется click/focus, все основные действия доступны с клавиатуры. На телефоне столпы и timeline прокручиваются внутри своих областей.
