# Astrowed — Digital Destiny Lab

Исходное состояние: репозиторий содержит техническое задание, код приложения отсутствует. Визуальный документ описывает желаемое будущее состояние, а не фактически существующие функции.

Next.js App Router + React + TypeScript. Слои: `domain/bazi` (детерминированные вычисления), `data` (Drizzle/PostgreSQL), `services` (доступ и сохранение), `components` (интерфейс), `scenes` (визуализации), `styles` (токены). Структурированный результат движка передаётся сценам без бизнес-логики внутри сцены.

Публичные: обсерватория, калькулятор, демонстрационная карта, Explore, опубликованные статьи. Закрытые: клиенты, карты, консультации и CMS. Начальная авторизация — единый кабинет консультанта с подписанной HttpOnly-сессией; многопользовательские роли и OAuth — отдельный этап. При отсутствии секрета кабинет закрыт.

Публичный расчёт не сохраняет персональные данные автоматически. Сохранение доступно только в кабинете. Секреты остаются в ENV и не попадают в клиентский JavaScript. Миграции запускаются отдельно от приложения.
